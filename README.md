# Система учёта питания в столовой

## Назначение

Приложение предназначено для автоматизации учёта питания в столовой.
Система позволяет хранить информацию о посетителях, приёмах пищи
и выполненных операциях.

Основная задача проекта — упростить процесс учёта питания и обеспечить
удобный просмотр информации о посещениях столовой.

## Целевая аудитория

Предполагаемые пользователи приложения:

- сотрудники столовой;
- администраторы;
- пользователи, ответственные за учёт питания.

## Предметная область

Предметная область проекта связана с организацией питания в столовой
и учётом посещений. Система должна позволять фиксировать информацию
о пользователях, приёмах пищи и соответствующих операциях.

## Основные сущности

- Пользователь — человек, для которого ведётся учёт питания.
- Приём пищи — информация о приёме пищи пользователем.
- Блюдо — информация о блюде, доступном в столовой.
- Заказ — набор выбранных блюд.
- Оплата — информация об оплате питания.

## Основные функции

На начальном этапе планируется реализовать:

- добавление информации о пользователе;
- добавление записи о приёме пищи;
- просмотр записей о питании;
- просмотр доступных блюд;
- формирование заказа;
- учёт стоимости питания;
- поиск информации.

## План развития

На следующих этапах планируется:

- разработка веб-приложения;
- подключение базы данных;
- реализация пользователей;
- разработка API;
- контейнеризация приложения;
- настройка CI/CD.
